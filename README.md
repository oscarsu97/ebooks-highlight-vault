# ebooks-highlight-vault

An [Obsidian](https://obsidian.md) vault holding my e-book highlights, kept in sync with this repository so I can browse them on GitHub.

## Folders

| Folder | Source | Imported by |
| --- | --- | --- |
| `ibooks-highlights/` | Apple Books | [apple-books-import-highlights](https://github.com/bandantonio/obsidian-apple-books-highlights-plugin) plugin, which reads the Apple Books database on the laptop |
| `PaperFolio/` | Kobo eReader | PaperFolio (`paperfolio-kobo`) plugin, which reads the Kobo database that the Kobo eReader syncs to, then writes the notes into Obsidian |

Each book is one Markdown note. The files in these folders are generated by the plugins, so edits may be overwritten on the next import. `PaperFolio/00_Kobo Highlights Index.md` is an auto-generated index of the Kobo books.

## Syncing to GitHub

The [obsidian-git](https://github.com/Vinzent03/obsidian-git) plugin commits and pushes changes from the vault to this repository.

## What is not in this repository

The `.obsidian/` folder (plugin settings, workspace state) is excluded through `.gitignore` because plugin settings can contain local paths and tokens. Only the highlight notes are published.
